## 🚀 Deploy to Render.com (Free)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

### Environment Variables (set in Render Dashboard)

| Variable | Required | Description |
|---|---|---|
| `VT_API_KEY` | ✅ Yes | VirusTotal API key — [get free key](https://virustotal.com) |
| `ABUSEIPDB_KEY` | ✅ Yes | AbuseIPDB API key — [get free key](https://abuseipdb.com) |
| `FLASK_SECRET_KEY` | ✅ Yes | Auto-generated by Render (leave as `generateValue: true`) |
| `APP_URL` | ✅ Yes | Your Render URL e.g. `https://threatintel-analyzer.onrender.com` |
| `MAIL_USERNAME` | Optional | Gmail for password reset emails |
| `MAIL_PASSWORD` | Optional | Gmail App Password (16 chars) |

## 🛠️ Local Development

```bash
# 1. Clone & setup
git clone https://github.com/YOUR_USERNAME/threatintel-analyzer.git
cd threatintel-analyzer

# 2. Create virtual environment
python -m venv venv
venv\Scripts\activate   # Windows
# source venv/bin/activate  # Linux/Mac

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure .env
copy .env.example .env
# Edit .env and add your API keys

# 5. Run
python app.py
# Opens at http://localhost:5000
```

## 🔐 Tech Stack

- **Backend**: Python 3.11 + Flask 3.0
- **Auth**: Flask-Login + PBKDF2-SHA256 + Permanent Sessions (365 days)
- **Database**: SQLite (local) / PostgreSQL (production)
- **APIs**: VirusTotal v3, AbuseIPDB v2, WHOIS
- **PDF**: ReportLab
- **Frontend**: Bootstrap 5 + Vanilla JS
- **Hosting**: Render.com
